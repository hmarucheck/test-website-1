Finish the Google setup

Sign-in needs an OAuth client ID from Google. It takes a couple of minutes:

  1. Open the Google Cloud credentials page and create a project if you don't have one.
  2. Configure the OAuth consent screen (External, app name “Veyloro”, your email as support contact).
  3. Choose Create credentials → OAuth client ID → Web application.
  4. Under Authorised JavaScript origins add https://hmarucheck.github.io — and http://localhost:8000 if you test locally. No redirect URI is needed.
  5. Copy the client ID into googleClientId in config.js and push.

The client ID is public by design and safe to commit. The client secret is not used here and should never be added to this repository.

This is a front-end demonstration. Google verifies who you are and returns a signed ID token, which this page reads only to greet you — there is no Veyloro server behind it, so no account is created and nothing is stored beyond this browser tab.
